# SmartGlass AI — Prototype 0.1

این نسخه یک نمونه اولیه وب‌اپلیکیشن فارسی برای تبلت اندرویدی است.

## امکانات فعلی
- ثبت عینک با سه تصویر (روبه‌رو، ۴۵ درجه، جانبی)
- ثبت برند، مدل، رنگ، قیمت، موجودی، شکل فریم و اندازه‌های واقعی
- ذخیره محلی اطلاعات و تصاویر در IndexedDB همان مرورگر/دستگاه
- جست‌وجو و حذف عینک‌ها
- تست روشن کردن دوربین جلو و گرفتن عکس آزمایشی (عکس مشتری ذخیره نمی‌شود)

## محدودیت‌های مهم
- هنوز هوش مصنوعی، رتبه‌بندی تناسب، پرو مجازی، فضای ابری و همگام‌سازی چنددستگاهی پیاده‌سازی نشده‌اند.
- داده‌ها فقط روی همان تبلت و همان مرورگر می‌مانند. پاک‌کردن داده‌های سایت/مرورگر ممکن است آن‌ها را حذف کند.
- دسترسی دوربین در مرورگر معمولاً فقط روی HTTPS یا localhost مجاز است؛ بازکردن فایل HTML به‌صورت مستقیم برای تست دوربین کافی نیست.
- این نسخه را برای اطلاعات واقعی مشتری استفاده نکنید.

## روش اجرای آزمایشی
1. فایل ZIP را از حالت فشرده خارج کنید.
2. فایل‌ها را روی یک میزبان وب با HTTPS قرار دهید (یا روی کامپیوتر توسعه‌دهنده با localhost اجرا کنید).
3. نشانی HTTPS را در Chrome تبلت سامسونگ باز کنید.
4. از منوی Chrome گزینه Add to Home screen / Install app را انتخاب کنید.
5. ابتدا با چند عینک آزمایشی، ثبت سه عکس، ذخیره و جست‌وجو را بررسی کنید.
6. سپس در بخش مشتری، اجازه دوربین را بدهید و روشن/خاموش شدن دوربین را آزمایش کنید.

برای نسخه بعدی باید سرور، ورود مدیر، ذخیره‌سازی ابری و سرویس AI اضافه شود.
